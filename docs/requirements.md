# MARQUEE requirements checklist

Every rule, feature and "Done when" from the master prompt, numbered. **M** is the milestone that delivers it. **Proof** is the test or screenshot that shows it works (`UT` = unit test in MARQUEETests, `UI` = XCUITest journey in MARQUEEUITests, `SS` = CI screenshot name). Status: ✅ done and proven · 🟡 built and waiting for CI to prove it · ⬜ not started.
